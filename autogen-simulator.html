AutoGen agent roles
👤
UserProxyAgent
Represents the human or task initiator. Can pause the loop for human approval, execute code in a sandbox, and feed results back into the conversation.
🔀
GroupChatManager
Coordinates turn order in multi-agent group chats. Decides which agent speaks next and enforces the stop condition to prevent infinite loops.
🗺
Planner (AssistantAgent)
Reasons about the task, breaks it into steps, and drafts an approach. Relies on high MMLU and GPQA scores for breadth and expert reasoning.
💻
Coder (AssistantAgent)
Writes and iteratively fixes code via the built-in executor loop. HumanEval and SWE-bench Verified are the key benchmarks for predicting its real-world output.
🔍
Critic (AssistantAgent)
Reviews outputs for errors, hallucinations, and unsupported claims before they are finalised. Acts as an application-level TruthfulQA check.
Key features
● Conversation loop — agents talk until a stop condition is met
● Code executor — auto-runs code, feeds errors back to Coder
● Human-in-the-loop — UserProxy can pause for human approval
● Tool calling — agents can use search, APIs, and file access
